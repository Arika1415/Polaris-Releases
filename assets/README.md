# 演示素材来源

四张当前动图均于2026-11-19使用Polaris 1.16.0原生UI及公共控制器连续录制，背景是程序绘制的模拟桌面，包含菜单栏、Dock和样例窗口；接棒段使用留出空间的桌面排布以便同时观察两个窗口。镜头连续跟随、局部放大，指针与操作经过编排，不是静态截图淡入导览。

- `polaris-drag.gif`：拖动与渐进吸附、约0.55秒停留、就绪边框快速闪烁、松手收成边条；悬停仅高亮，首次点击恢复球体，第二次点击展开，再收回。使用当前原生拖动和贴边状态机／动效。
- `polaris-expand.gif`：点击展开、原生文本编辑器输入、收起、再次展开验证草稿保留；镜头按实际编辑器位置取景。
- `polaris-chat-images.gif`：从球体进入样例聊天，显示图片输出，打开原生图片预览，镜头观察细节，关闭并回到球体。示例图片使用Polaris品牌图案，不声称由真实模型生成。
- `polaris-handoff-files.gif`：准备交接、审阅内容、接收Agent和文件清单、交付、核对及明确确认后归档。Agent回复来自隔离样例；真实文件服务对临时样例项目执行清单、复制和校验。演示中的`/tmp/Polaris-MotionDemo-*`仅为临时夹具目录，不是用户项目。

录制只采集演示进程自己创建的窗口ID，再合成模拟背景；不读取用户真实桌面、不录音、不连接真实Agent、不包含账号凭据或聊天。四段均检查实际状态推进和原生动画，不把样例回复当作真实Agent的执行证据。软件功能和发布包版本仍为1.16.0（101）；此次只更新演示素材。

`polaris-workspace.gif`是历史首页概览，保留供追溯，不再作为当前版本主图。图标和下载按钮沿用Polaris品牌资源。


## 视频标准重制

四段演示均提供50fps GIF和配套50fps H.264 MP4。视频宽1280像素，动图宽1040像素，高度跟随模拟屏幕等比取偶数；保留菜单栏和Dock，画布两侧不留空白。工作区／标题居中，贴边条始终位于屏幕真实边界。镜头使用快速靠近、柔和收稳的阻尼曲线，指针具有加速、减速和停顿；推近后字幕淡出，保留原生界面文字；循环末尾回到球体与全景，避免从展开页直接跳回开头。

窗口采集与GPU视频合成分离，采用当前原生UI像素和实际采样时间；大窗口静止时限频刷新。50fps指成片合成节奏，原生窗口快照更新率随内容和WindowServer变化；不使用光流补帧或把旧低帧率动图简单提速。MP4保留全彩画面，适合检查细节；GIF受调色板限制，适合README自动播放。
