# Polaris 操作指南

适用于 **Polaris 1.17.3（106）macOS公开预览版**。返回[产品介绍与动图](../README.md)。

## 1. 下载和安装

- 当前发布包适用于Apple Silicon（M系列Mac），最低编译目标macOS 13.0。macOS 13.6.7、Intel与Windows没有完成对应实机验收，不能把本包当作这些平台的正式验收版。
- 从[本版Release](https://github.com/Arika1415/Polaris-Releases/releases/tag/v1.17.3)下载 `Polaris-1.17.3-106-arm64-release.dmg`，打开后将Polaris.app拖到Applications。不要直接长期运行镜像里的应用，也不要下载Source code ZIP代替安装包。
- GitHub公开包无需登录即可下载。`.sha256`是可选校验文件，不是运行组件。
- 已有用户保存任务并正常退出旧版，替换原安装位置的Polaris.app，避免保留多份应用。
- 当前是ad-hoc签名预览包，尚未完成Apple公证。若系统拦截，请先确认下载来自本仓库，再按macOS“隐私与安全性”的提示处理；不需要关闭整个系统的安全保护。

## 2. 首次部署

1. 先按对应Agent的官方说明安装并配置本机Codex或DeepSeek Harness，完成该Agent自己的登录／服务配置。Polaris安装包不包含模型服务、订阅或开发者账号。
2. 启动Polaris，等待部署引导进行完整性、版本和基础环境检查。
3. 选择检测到的Agent，阅读功能介绍，按提示验证该Agent的连接与登录状态。没有可用工具时，先完成安装，再重新检查。
4. 完成后从悬浮球开始使用。可在 `… → 首次部署引导…` 再次打开引导。
5. 语言可在界面语言选择中切换中文、英文或跟随系统。

只授予实际需要的macOS权限。分析屏幕需要系统屏幕录制权限；普通文本对话不应被理解为已经拥有这项权限。权限入口为 `… → 屏幕录制权限…`，按系统提示授权，必要时保存任务并正常退出重开。当前ad-hoc签名不能保证每次更新后授权持续有效。

## 3. 发起与继续项目

1. 点击悬浮球展开面板。
2. 在开始新项目之前，通过 `… → 工作目录` 选择所需目录；未指定时，首次发送会为新项目建立独立目录。
3. 输入任务，点击发送箭头；`⌘Return`也可发送。不要把多个无关项目都放进一个公共工作目录。
4. 项目卡片保留所属Agent。点击卡片或从“全部记录”返回原会话继续；无需复制整段旧聊天重建项目。
5. 查看回复、执行步骤及工具输出。停止操作需要等待Agent确认，不应仅因界面收起就判断任务结束。

如果发送不可用，先查看输入区提示：Agent未连接、账号／模型未就绪、会话仍运行或正在停止、受保护的只读会话等会阻止发送。使用“重新检查”更新状态；保留草稿，不要连续重复发送同一任务。历史读取失败时可使用“重新读取历史记录”。

## 4. 双Agent与模型选择

- 通过 `… → 切换 Agent` 选择Codex或DeepSeek Harness。选择展示对象不等于断开另一个Agent；两者可以独立执行任务。
- Codex为绿色主题，DSH为蓝色主题。项目卡片标注归属，模型选择也按Agent品牌隔离。
- 模型按钮位于发送键旁，选择该Agent返回的可用模型；列表、登录和模型权限取决于Agent本身。
- 回到另一个Agent的原项目，继续其原生会话；切换Agent本身不会把当前项目自动移交给对方。
- DSH支持Polaris本地保存项目的恢复和续问；暂不导入其桌面全部原生历史，附件等能力有额外限制。

## 5. 图片与附件

1. 对支持附件的Agent，点击输入区回形针选择文件，或将本地图片文件拖入输入区。
2. 图片先显示小缩略图；可在发送前移除。发送后缩略图保存在消息中。
3. 点击消息卡片或输入区缩略图放大查看，使用放大／缩小按钮，按Esc或“关闭”返回。
4. 支持的Codex图片生成结果在完成后导入并保存到本机。Agent最终回复里明确引用的本地Markdown图片也可展示，相对路径按当前项目目录解析。

图片生成仍依赖Agent的工具、账号与模型能力。本轮验证了结果接收与展示，没有以真实模型生图作为验收依据；不表示每个Agent、模型都支持生成。DSH目前不提供附件发送。

本地预览单张最多100 MiB，生成结果导入单张最多32 MiB；超大像素、损坏、移动或无法解析的图片显示不可用。GIF等动图显示首帧。外部URL不自动联网加载；更新前只保存附件名称的老消息不会扫描磁盘找回原图。

## 6. 准备接棒与交付成果

1. 先确认来源项目的任务已停止或完成；在该项目中选择 `… → 准备接棒…`，项目卡片右键也有入口。
2. 在“整理交接包”中选择是否准备并交付项目文件。程序汇集对话和文件元数据，点击“让当前Agent整理”。总结在独立文本会话中完成，不继续来源任务或让模型调用工具查文件。
3. 等待整理完成，审阅并修改交接内容。总结包含目标、要求、进度、决策、成果、验证与下一步，但总结本身不是经过重新验证的事实。
4. 选择接收Agent，指定新项目或已有项目，核对接收目录；审阅待交付文件清单。缓存、常见凭据、其他Agent规则等默认排除，但仍应自行检查选择的文件。
5. 在确认页点击“交付文件并请求核对”。程序先复制并校验成果，再创建／继续接收会话。新项目执行于独立目录；已有项目收到独立子目录，保留原工作目录和历史，不覆盖原文件。
6. 接收方返回核对回复后，阅读它对现状、阻塞和下一步的判断，点击“确认核对结果并继续”。程序再次校验已交付文件，通过后才发送继续任务；来源项目随后归档并标明交接去向。

整理窗口可返回会话、拖动或最小化，后台整理不因此等于已经完成移交。送达不明时先检查接收方记录，程序不会自动反复发送。复制失败、结果文件变化或接管确认失败时保留来源项目和记录，先处理提示再明确重试。已有来源关系和交接包可追溯。

文件引用不是读取沙箱，不能保证接收Agent绝不会读取其他文件。接收方仍遵守其原生权限和实际工作目录；不要把公共Workspace、其他项目目录或来源目录权限误当成目标项目权限。

## 7. 项目命名、备注、归档和恢复

在项目卡片右键选择“修改项目名…”、“添加备注…”／“编辑备注…”或“归档项目”。归档收起项目条目，保留工作记录与会话引用；可在“全部记录”中的归档项目恢复。

运行中或状态不明的项目应先处理任务状态。归档不会删除实际目录，也不会自动制作完整文件备份；成果文件交付只复制经过审阅的所选文件，不等于备份全部项目。

## 8. 全局规则与项目规则

- 全局规则：主面板 `… → 规则管理…` 中明确确认保存。
- 项目规则：项目卡片右键“项目规则…”，只作用于绑定的项目目录。
- 保存后从下一条发送或运行中补充生效，不强行重启当前任务。消息旁的“规则版本…”可追溯发送时确认的版本。
- 原生Agent有效的全局／项目规则仍会生效。普通Markdown不会自动变成Polaris全局原则，也不会把其他项目规则复制给接收方。

## 9. 悬浮球和阅读历史

- 点击球体展开，收起面板后运行任务继续。
- 拖动到顺手位置；靠近屏幕边缘有吸附反馈，停留约0.55秒后边条快速闪烁，松手贴边。可通行的多屏接缝不作为外边缘。
- 悬停边条只高亮并轻微放大；点击恢复悬浮球，再点展开工作空间。
- “跟随新消息”是阅读偏好。手动浏览历史时暂停自动追随，返回底部后恢复；需要时使用“更早的消息”加载历史。

## 专注模式与退出应用

打开项目后点击顶部展开图标，或在项目卡片右键选择“进入专注模式”。专注模式使用macOS原生全屏Space，支持系统的桌面切换与Mission Control；纯黑背景、14–16pt轻字重、居中的宽正文，无聊天气泡或对话人名称。新回复逐字渐入，历史直接显示；底部保留原生输入、模型选择与发送。

右上角“退出专注模式”、Esc或⌘W返回原面板，保留草稿、阅读位置与任务。退出专注模式不是停止任务。触控板桌面切换手势由macOS系统设置管理。

Polaris显示在程序坞中，右键图标选择“退出”，也可在Polaris激活时按⌘Q。有任务运行时会确认是否退出；收起面板和关闭专注界面仍让程序继续运行。

## 10. 更新和数据位置

通过 `… → 更新与版本…` 检测新版，确认安装后下载、校验并替换应用；正常退出重启后启用。运行任务的退出确认仍保留，取消退出不会强行终止任务。1.10.43及更早版本须先手动安装新版一次。

- 规则、历史、项目与图片：`~/Library/Application Support/Polaris/`。
- 默认项目：上述目录中的 `Projects/`；用户明确选择的外部项目留在原位置。
- 生成图片：上述目录中的 `GeneratedImages/`；不是启动时可删除的缓存。
- 更新下载缓存：`~/Library/Caches/Polaris/UpdateDownloads/`，按应用专属缓存策略清理。

旧 `CodexTaskPanel` 数据路径只作为兼容入口迁移，不代表应重新建立公共混杂目录。出现独立数据冲突时不自动合并或覆盖。启动清理不会扫描删除用户Markdown、项目、归档、图片或版本备份。

## 11. 发布包一致性与反馈

1.17.3安装镜像已检查版本、架构、最低系统和签名；维护本机应用的临时副本经过相同剔除符号与签名处理后，全部39个文件与发布镜像一致。原始开发安装的符号及签名包装可能使哈希不同。真实镜像安装与精确回滚已通过。公开附件已无需登录回下载，SHA-256与上传原件一致；回下载镜像中的39个文件也通过上述比对。在线更新API与真实下载校验通过，完整校验值见本版Release。

不同电脑上的Agent安装、账号、模型权限、macOS版本与系统授权仍需分别配置。反馈问题时请提供Polaris版本／构建号、系统与芯片、所选Agent、复现步骤及提示文字；截图遮盖项目私密信息，不提交API Key、密码或完整聊天记录。
